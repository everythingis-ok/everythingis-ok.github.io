在 Flask 中，静态目录（static）是用来存放静态文件的，例如：

  • CSS 样式表
  • JavaScript 脚本
  • 图片（如 PNG、JPG、SVG）
  • 字体文件（如 TTF、WOFF）
  • 其他前端资源

如何访问静态文件

在浏览器中访问的 URL 为：

Flask 会自动将 static 目录中的文件映射为 /static/ 路径开头的 URL。

往 Flask 的静态目录写入一个文件，准备“盲打文件”然后从前端页面读取结果，这是一种盲注回显替代方式。
